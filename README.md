# SkyGeo

A lightweight C++17 computational geometry library with tools for running experiments, packing submissions, and visualizing geometric objects.

The experiments may contain some of the implement in *Computational Geometry: Algorithms and Applications(Mark de Berg, Otfried Cheong, Marc van Kreveld, Mark Overmars)*.

Still working...😋

## Requirements

- C++17 compiler or above
- CMake 3.12+
- Python 3
- Windows CMD (selective)

Install the Python visualization dependencies:

```bash
py -m venv venv
venv\Scripts\activate
python -m pip install pyqtgraph PySide6
```

Each directory directly under `experiments/` is treated as a separate CMake executable target.

## Commands

This commands are written for convenience, and it can be directly excuted under `SkyGeo/` in Windows CMD.

### `run`

Build and run an experiment:

```bat
run -o test
```

Run an already-built experiment:

```bat
run test
```

The `-o` option configures the CMake project and builds the selected target before running it.

### `pack`

Pack an experiment and its local SkyGeo headers into a single C++ source file:

```bat
pack test
```

The generated file is written to the project root:

```text
test.cpp
```

This is used by me to verify my code's correctness on some Online Judges since they only support submitting one file each time.

### `visualize`

After an experiment writes geometric objects using the functions from `visualize.hpp`, display its generated `visualize.out` file:

```bat
visualize test
```

The visualizer currently supports points, lines, segments, and polygons. It is based on Python `pyqtgraph`.

It has a very simple protocol like 
```
POINT x1 y1
SEGMENT x1 y1 x2 y2
```
which will automatically generated by `visualize.py`.
